# 4.1 一维数组
---
## ==🔵Vocab==

1. 中括号 - `[]`
2. 大括号 / 花括号 - `{}`

---
## ==🔵一维数组==

#### ==🟡连续性==

`int` takes 4 bytes

```c
a[0] // 0x00
a[1] // 0x04
a[2] // 0x08
a[3] // 0x0C
```

---
## ==🔵Declare an Array==

```c
int a[5]; // 5 ints, stops at a[4]
a[5] = {1,2,3,4,5}

#define N 10
int a[N];
	#or 
const int N = 10;
int a[N];
```

---
## ==🔵Number of Elements==

`总字节数 = sizeof（数据类型） X 数组长度`

```c
int n = sizeof(a) / sizeof(a[0])；
```

---
## ==🔵Find the Address of Variables==
```c
int a[10];

printf("%p", (void *)&[0]); // void is generic pointer, only store address
```

---
## ==🔵Add Values to an Array by `scanf`==

```c
#include <stdio.h>

int main()
{
    int a[3];
    int i;

    for (i=0;i<3;i++)
    {
        scanf("%d", &a[i]);
    }

    for (i=0;i<3;i++)
    {
        printf("%d ",a[i]);
    }

}
```

---
## ==🔵Add Values to Array by Normal Way / 数组的初始化==

```c
int a[4] = {1,2,3,4};

# or

a[0] = 1;
a[1] = 2;
a[2] = 3;
a[3] = 4;


# or

int a[] = {1,2,3,4} // the computer recognize it
```

---
## ==🔵Turn {1,2,3} to 321==

Use this formula
	n = n * 10 + data

---
## ==🔵Make Sure All Elements Start at 0==

```c
#define N 10

int a[N] = {0}
```

---
## ==🔵选择排序 / Selection Sort==

It is a way of sorting by repeatedly select smallest element from unsorted list and put it in the front.

---

## ==🔵冒泡排序 / Bubble Sort==

sorts an array by repeatedly comparing **neighboring** elements and swapping them if they are in the wrong order.


---
## ==🔵插入排序 / Insertion Sort==

sorts an array the way you sort playing cards in your hand: take the next card and **insert it into the correct place** among the cards you already sorted.


---
## ==🔵字符数组==
---
`\0` 结束符
```c
char a[N]
```
---
## ==🔵有效长度==
---
```c 
char a[4] = {'1','2','3','4'};
char b[4] = {'1','2','3','\0'};
char static c[4] = {'1','2','3'}; // all default is 0
```
---
## ==🔵`printf` and `scanf` for 字符数组==
---
```c
scanf("%s",s);
printf("%s",s);
```

Why not use &?
Because s is not a  首地址, so it does not need & to point out address clearly.

---
## ==🔵`gets` and `puts`==
---
```c
#include <string.h>

gets(s);
puts(s);

puts(s+2); // start from index 2
```

---
## ==🔵`for` statement modified==
