## ==🔵用户自定义函数 / user-defined functions==

####  ==🟡1. `char` function==
```c
char lower_to_upper (char c)
{
	if (c >= 'a' && c <= 'z')
	{
		return c = c - 32;
	}
	return c; // 有返回值
}
```

#### ==🟡2. `void` function==
```c
#include <stdio.h>

void echo_start()
{
    printf("Ready Go!\n"); // 没有返回值
}

int main()
{
    echo_start();
}

```

#### ==🟡3. `int` function==
```c
#include <stdio.h>

int sum(int a, int b, int c)
{
    return a + b + c;
}

int main()
{
    int a=1,b=2,c=3;

    printf("%d", sum(a,b,c));
}
```

## ==🔵函数声明 / Function Declaration

Always declare function, if your function expression is below main function.

```c
int main()
{
	char lower_to_upper(char c);
}
```

## ==🔵形式参数 & 实际参数==

Formal parameters and Actual Parameters

```c
char lower_to_upper(char c); // 形式参数

lower_to_upper(c) // 实际参数
```

max = find_max(2,find_max(1,3,4))
